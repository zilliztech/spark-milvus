表描述

连接器的读、写、搜索、建索引只认一种内部结构：表描述。表一级是 Snapshot，单元一级是 milvus-storage 的列组；每种数据源只负责把自己的元数据翻译成表描述。

结论原理简洁性的好处设计的好处

一、结论

  1. Snapshot 是所有数据源共用的表描述。Milvus 快照、milvus-backup 导出、开放格式、用户声明的 schema 都产出它（决策 25）。
  2. 表描述是内部接口，用来解耦模块、扩展数据源、组合功能，不对外公开。
  3. 单元一级是 milvus-storage 的列组：哪些列、什么格式、哪些文件的哪几行，以及每个文件的格式属性。
  4. 删除在两处执行：单元内的删除与合并由格式读取器执行，跨单元的按键删除由 core.delete 执行。
  5. 行身份以位置地址为准，即单元编号加单元内行号；键列与稳定行 id 是可选规则。
部分表描述里的形态
版本数据源自己的版本号，原样记录：Milvus 快照、Iceberg 与 Paimon 的 snapshot id、Lance 的版本
schema字段 id、Milvus 类型、向量维度、主键
单元一组列组，或一个在 executor 上展开成列组的 milvus-storage 清单
跨单元删除键列、删除文件、先后依据：行时间戳或文件序号
行身份位置地址必有；键列、稳定行 id 按数据源提供
索引与统计可用、确认无、未知三态，载荷按引擎和统计种类区分
位置与凭证每个存储位置一组 fs.* 或 extfs.* 属性

二、原理

  1. 每种数据源在一个版本下都是一份 schema 加一组单元，单元由文件组成。单元在各数据源里分别是 Milvus 的段、Iceberg 的数据文件、Hudi 的 file slice、Lance 的 fragment、Paimon 的 split。表描述按这个形状定义，任何数据源都能填进去。
  2. 表一级放下游模块据此做决定的信息。规划用行数和大小，剪枝用分区和统计，投影用列与文件的对应，回表和索引结果用位置地址，搜索用向量类型和维度，跨单元删除用键列和先后依据。
  3. 单元一级只说明读哪些文件的哪几行。格式特有的信息原样放进文件的属性，交给该格式的读取器解释：Iceberg 的删除元数据、Lance 的数据集版本、Paimon 的合并方式都在这里。Milvus 的外表用同一种列组包装 Parquet、Vortex、Iceberg 和 Lance。
  4. 删除归到能执行它的地方。删除向量只涉及一个单元，按键合并发生在一个 Hudi file slice 或一个 Paimon split 之内，这两类由读取器执行。Milvus 的主键删除和 Iceberg 未分区的按列值删除跨越单元，由表一级执行，规则相同：同键且更早的数据被删除，Milvus 按行时间戳比先后，Iceberg 按文件序号比先后。
  5. 行身份统一成位置地址。位置地址是 (单元编号 << 32) | 单元内行号，Milvus 外表的虚拟主键与 Lance 的行地址都是这个形式。回表按它取列，Milvus 索引的 label 与 Lance 索引引用的都是它。
  6. 翻译在 driver 上做一次。executor 收到的是单元描述，读批次的路径保持今天的样子。

三、简洁性带来的好处

  1. 下游只认一种结构。读、写、搜索、建索引四个模块不区分数据源，接入新数据源时下游代码不动。
  2. 读取只有一条链路。所有单元都以列组交给 milvus-storage，投影、切片、批大小、指标各只有一份实现。
  3. 概念数量不增加。表一级沿用 Snapshot，单元一级沿用 milvus-storage 列组，两者都已在代码里运行。
  4. 数据路径没有额外开销。表描述只在 driver 规划时存在，不转换数据，executor 逐行逐批的开销与今天相同。

四、这样设计带来的好处

  1. 接入新数据源只写一个翻译。开放格式由 milvus-storage 展开成列组，用户声明的 schema 直接填进表描述。
  2. 各格式按原语义读出。删除向量、按键合并由该格式的读取器执行，读出的行与原格式一致。
  3. 功能可以任意组合。模块之间传递同一种结构，例如读一份 Iceberg 数据、建索引、写成 Milvus 快照，三步交接的都是表描述。
  4. Milvus 数据的读法保持一致。Milvus 快照翻译成表描述后读出的结果与今天相同，现有单测和 UAT 套件直接验收。
  5. 与 Milvus 用同一种文件描述。连接器和 Milvus 外表都用 milvus-storage 列组描述文件，同一份数据在两边的文件、行范围和格式属性一致。
  6. 精确搜索、索引搜索、建索引共用行身份。三者都按位置地址定位行，搜索结果可以直接回表，也可以直接和索引结果比对召回率。
